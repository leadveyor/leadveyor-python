# Contributing

Most of this SDK is generated from the Leadveyor API's OpenAPI spec, so the methods, parameters and models always
match the API. Files that start with a `GENERATED` comment are rewritten on every release: please open an issue
instead of a pull request for them.

Bug reports, questions and pull requests for the hand-written parts (HTTP client, errors, pagination, webhooks,
README) are welcome. Security issues: support@leadveyor.com, not a public issue.
